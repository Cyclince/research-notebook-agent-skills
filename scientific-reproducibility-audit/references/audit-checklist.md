# 科学方法回归检查表

| 类别 | 验收问句 |
|---|---|
| 论文与源码 | 论文 DOI、公式/附录、官方代码版本是否已核实？有无不一致？ |
| 数据身份 | 数据路径、哈希、样本纳入规则、时间/空间域、测量单位是否相同？ |
| 输入清洗 | NA/NaN/Inf、零、失效标志、不收敛、异常值筛选是否一致？ |
| 计算 | 算法步骤、数值方法、求和/排序顺序、函数版本、拟合约束是否一致？ |
| 参数 | 超参、默认值、阈值、网格/时间步长、seed 是否一致？ |
| 统计 | 分组独立性、重复测量、聚合方式、分母、置信区间/SD/SE 含义是否相同？ |
| 输出 | 列名、量纲、单位、有效范围、缺失/QC是否一致？ |
| 图表 | 是否真实读取保存数据、图例/单位/样本数正确、可单独重绘？ |
| 环境 | Python/R/MATLAB/Julia 版本、关键依赖、硬件/平台、并行设置记录？ |

记录格式、对齐规则和容差定义统一采用 [结果对齐与验收协议](result-contract.md)；使用 `../assets/validation_matrix_template.csv`。先核验完整键集合再比较；不能只挑匹配样本。标量 CSV 可使用 `../scripts/compare_csv.py`，随机算法须另设有依据的统计验收。
