# 真实数据输入工作流

## 先把输入接通，再执行算法

先扫描用户项目已有数据目录、配置、下载脚本、数据字典与论文补充材料，确定算法真正消费的输入：原始观测、特征矩阵、标签、标定文件、模型权重或保存结果。记录每个必需输入及其依赖关系，不能只提供一个 DataFrame 占位符就开始“复现”。

数据获取优先级：用户已授权的本地真实输入 → 论文/作者正式数据及固定版本 → 有方法适用性依据的公开真实数据。第三类属于方法迁移或输入演示，不能冒充原论文结果复现。用户要求模拟研究时才启用显式模拟模式，写明生成模型/seed和用途；任何缺失都不能触发自动造数。

先通过可用文件与连接器寻找。公开数据从论文、作者代码或官方托管页核实来源与访问办法，确认许可、版本、大小和校验值后获取。受限数据应使用用户提供的授权路径；访问凭证不写进 Notebook、日志或发布包。不能访问时生成简短 data_request.md，列出必需文件/格式/字段/单位/分组/获取步骤与当前阻断项，询问最小必要信息，不继续制造替代结果。

## 可交付的输入入口

每个项目需有一处清晰可编辑配置，包含：

- 数据集 ID/版本、文件路径或清单、来源 URL/引用、source_type 与科学用途 role（paper_reproduction / method_transfer / input_example）。
- 文件格式/编码/分隔符；表格字段映射、联合主键、单位、缺失标记；数组的 shape/dtype/轴定义；图像的通道、像素尺寸；时空数据的 CRS/时区与索引。只填写适用项。
- 论文数据划分、样本纳入范围、标签与特征连接键、校准和权重等附加输入。训练/验证/测试划分固定，预处理拟合只使用允许的训练部分。
- 输入哈希/可信上游清单、预期规模、必要字段与允许类型、输入到原算法参数的对应关系。单位换算或重采样显式登记，不偷偷修正。

提供数据字典与可运行的实际读取单元。表格可以本地文件路径为主；批量文件用清单或可配置路径模式；必要时可选文件选择控件，但普通路径配置必须能运行。CSV 只是随附演示适配器的能力，科研项目的 NetCDF/HDF5/栅格/图像/矩阵等应采用对应原生读取器，不强制转成 CSV 或丢掉维度/元数据。

## 输入预检与可视检查

正式计算前运行预检：文件存在/非空/可解码、哈希/版本、字段/维度、主键与连接覆盖、类型与单位、缺失/非法值、重复、样本范围、标签及分组。展示输入来源、路径/文件数量、规模、字段/轴、单位、数据头或适当缩略图，以及缺失/QC 摘要；私密内容应脱敏。

预检不能静默填零、重编码 ID、删样本或重采样。必要清洗按原方法显式实现，并保存逐项排除原因和前后数量。将输入身份与 QC 摘要合并到已有 provenance 记录；没有现成记录时再建一份清单，后续计算与绘图引用同一份证据。

缺少必需输入、来源不明、字段不匹配、单位不明或输入版本改变时 BLOCKED；结构合法不代表数据来源已获独立证实。真实性不能靠 source_type 字符串自动验证。论文数据不可得时可交付适配器与请求清单，报告“接入未完成”，不能把模板可运行写成论文已复现。

## 本包的两个入口

scientific-code-to-notebook 提供 notebook_template.ipynb：默认读取待配置的 input_config.json，缺少真实输入时停止。real_data_example.ipynb 使用随包的 Palmer Penguins 真实观测表，展示路径/字段/单位/缺失/哈希配置、QC、保存和独立重绘。示例采用分组统计，是输入示范，不是通用论文算法。

其 input_adapter.py 支持 CSV/TSV 到示例 sample_id/group/value 三字段映射，所有记录保留原文件；其他算法须定义自己的输入结构。sample_id 可引用原始字符串列；仅在配置明确允许时使用来源行号，行号不证明生物个体身份或独立性。输入配置及适配器自身哈希也进入缓存证据。

## 逐阶段验收

记录 input:availability、input:identity、input:schema、input:units、input:qc、input:preview、input:role 适用检查，沿用统一验收 schema，check_type 使用 provenance/structure/qc。分别报告：输入接通、原算法运行、数值对照、论文结论验证。只有前一个阶段有证据时才能推进；真实公开数据跑通不等于原论文数据验收通过。
