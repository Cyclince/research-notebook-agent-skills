# 从科学问题选择图型

| 需要回答的问题 | 优先考虑 | 必须核对 |
|---|---|---|
| 不同条件的均值/估计与不确定性 | 点区间图；必要时分组柱图 | 类别与系列顺序显式定义；误差含义、n 和配对关系 |
| 数据分布与离群点 | 散点叠加箱线/小提琴、ECDF | 原始有效样本、密度带宽；不能用均值柱替代分布结论 |
| 时间/连续自变量的变化 | 线与点、已有区间带 | x 单位与排序；缺测时留间断，不把跨缺口连线当观测 |
| 二维数值/相关矩阵 | 热图与色标 | 行列标签/顺序、缺失掩码、色标单位及范围 |
| 两个变量的关系 | 散点；大数据时明确计数的 hexbin | 对齐后的成对有效样本；缩放、采样和密度含义 |
| 多模型、多指标 | 多面板或长表点图 | 每项指标方向/单位；不把不同量纲强行共轴 |

## 柱图与点区间图

- 柱图以长度表达量，默认包含零；负值保留负轴。若合法的关注范围远离零，改用点区间图通常更清楚。确需非零基线或断轴时显式标注、解释，并评估是否误导。
- 同一组多系列柱中心可用 `x + (j - (m - 1) / 2) * width`；不要将任意方法当默认排序基准。标注值的精度由结果精度决定。
- 误差线来自保存的 SD/SE/CI；非对称区间用上下界距离，不默认等宽。CI 不包含估计值时先核对方法，不以截断为零“修复”。n=1 时不能把未定义 SD 画成 0。
- 重复测量可保留同一样本连线；独立性由研究设计决定，不以记录行数直接当 n。

## 趋势与区间

- 先对齐 x、估计和已有上下界，验证长度、有限值以及 `lower <= upper`。不要用视觉阴影、相邻点波动或未说明的固定比例制造 CI。
- 缺测以 NaN/掩码切断线或带；排序是显示变换，插值、平滑、回归属于需说明且有授权的方法变更。
- 密集曲线可拆面板；依靠线型和点形辅助区分，不只降低透明度。

## 热图

- 非负强度可用顺序色图；有科学中心的正负偏差可用以该中心对称的发散色图。缺失值与零必须有不同视觉编码。
- 可比面板共用 vmin/vmax/色标；不可比时分别标注单位和范围。不能每个面板各自归一化后暗示绝对量相同。
- 单元数字只在最终尺寸可读时保留；排序或聚类依据须可追溯，不能为了漂亮重排实验层级。

## 特殊图的适用限制

雷达图会受指标顺序和尺度影响，只有读者需要且归一化/指标方向有依据时使用，同时提供原数值表。涉及 3D、空间地图、概念示意时按任务采用适当工具；不因参考项目存在此图型而自动使用。人工示意与真实分析数据分别标记。
