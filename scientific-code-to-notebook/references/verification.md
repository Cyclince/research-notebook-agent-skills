# 原算法保真与数值验收

## 逐项测试

- **版本与输入**：原数据哈希一致、相同样本/时间/空间/筛选条件、单位一致。
- **算法**：同公式、同约束、同边界、同默认参数、同缺失/QC 规则、同聚合方式。
- **字段级移植**：原实现输出的每个字段（含 PlotID/样本 ID 等标识符的变换规则，如后缀剥除、大小写、命名映射）逐字段移植或登记为已知差异；验收对照字段集须覆盖全部可比较字段，不得只挑数值指标。
- **确定性**：对比绝对误差和相对误差；容差由量纲、精度和原实现决定，不能随意放宽。
- **随机计算**：保存 RNG seed、算法、库版本、并行设置；根据重复实验比较分布/统计量，而非强行逐元素一致。
- **特殊输入**：空、全缺失、单样本、异常单位、不收敛、溢出、重复记录。
- **图件**：绘图输入文件真实存在且**非空**（行数与预期一致）；图渲染无缺字形警告（中文图须已配置 CJK 字体）；空图或豆腐块图一律按 FAIL 处置，不得因"代码跑通"而验收。图中 n、分组、单位、误差条、显著性来源正确。
- **Notebook**：从空 Kernel Run All；独立只绘图路径；单个分析单元不依赖其他 Notebook 的内存。
- **方法追溯**：真实 DOI/文献章节/作者代码版本，区分原论文和研究适配实现。
