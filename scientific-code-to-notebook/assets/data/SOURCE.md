# Palmer Penguins 输入示例来源

真实企鹅测量记录，经 palmerpenguins 项目发布。固定来源提交：8957207b78d6ccd1b4654a9dd9c9041b657478ab。

CSV：https://github.com/allisonhorst/palmerpenguins/blob/8957207b78d6ccd1b4654a9dd9c9041b657478ab/inst/extdata/penguins.csv
项目与采集研究引用：https://allisonhorst.github.io/palmerpenguins/
许可：原项目 CC0，全文随附 PALMERPENGUINS-LICENSE；本 CSV 是原始下载字节，未修改。

344 条记录，species/island/测量值/sex/year 等字段，NA 表示缺失。示例按 species 汇总 bill_length_mm（毫米），排除该值缺失的两条记录，保留 342 条。来源行号仅作文件内追踪。科学角色是 input_example，不是任意目标论文的数据替代品；群体差异不作因果推断。正式使用须按源项目列出的数据与研究引用进行引用。
